PATCH 2026-07-02 - Rekapitulasi Pelanggan POS Desktop/Web + Optimasi Lag Ringan

Ruang lingkup:
1. POS desktop menyimpan nama pelanggan dan nomor telepon ke tabel sales lokal.
2. POS desktop menambah tab/menu Rekap Pelanggan.
   - default sort nama A-Z
   - search nama/nomor telepon
   - sort nama, nomor telepon, jumlah transaksi, total belanja, terakhir transaksi
3. Sync POS desktop -> web membawa customer_name dan customer_phone.
4. Pull sync web -> POS desktop membawa customer_name dan customer_phone.
5. Web menambah menu Admin -> Rekapitulasi Pelanggan, memakai permission customers.view.
   Manager cabang yang punya akses customers dapat melihat menu ini.
6. Optimasi lag ringan:
   - calculateShiftSummary memakai SQL aggregate, tidak lagi membaca semua transaksi shift untuk hitung ringkasan.
   - setelah bayar, POS hanya refresh status/pending/shift summary; tidak render ulang semua produk/kategori.
   - tambah index SQLite sales untuk shift/sold_at/group/customer.
